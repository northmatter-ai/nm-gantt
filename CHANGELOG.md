# Changelog

All `@northmatter-ai/*` packages share one version. See [RELEASING.md](RELEASING.md).

## 0.1.0 — unreleased

First public release, MIT-licensed. It's a preview: the engine hasn't been checked against real MS Project files to the minute yet (README → "Status against the build plan").

- `@northmatter-ai/calendar`: working-time calendars.
- `@northmatter-ai/schedule-engine`: CPM engine.
- `@northmatter-ai/schedule-commands`: document model and undoable edit commands.
- `@northmatter-ai/schedule-io`: MSPDI and Excel import/export.
- `@northmatter-ai/gantt`: React Gantt, phone view.
- `@northmatter-ai/construction-views`: tower × floor grid, line of balance, look-ahead.
